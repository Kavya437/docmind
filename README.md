# DocMind

DocMind is an AI-powered document intelligence platform that helps users understand PDF documents without reading every page.

## Features

- Upload and extract text from PDF documents
- Generate AI-powered summaries using Google Gemini
- Ask questions about uploaded documents
- Interactive document workspace with PDF preview
- Responsive modern UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Google Gemini API
- PDF.js
- Vercel
